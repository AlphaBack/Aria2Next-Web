设置

RPC 连接

浏览器直连需要 aria2-next 以 --rpc-listen-all --rpc-allow-origin-all 启动，或与本页面同源部署。跨域时请设置 --rpc-secret。

全局代理（aria2.changeGlobalOption）

仅提交被修改的键。留空表示不修改（沿用引擎现有值）。格式：http://[USER:PASS@]HOST:PORT 或 socks5://HOST:PORT。

引擎信息

全局选项（aria2.getGlobalOption / changeGlobalOption）

仅提交被修改的键。限速直接填字节数（如 2M 对应 2097152），留空表示不修改。

关于

Aria2Next Web — 面向 aria2-next 的单文件 Web 控制台，界面与交互参照开源项目 AriaNg，协议层兼容标准 aria2 JSON-RPC， 并实现了 aria2-next v3.0.9 的 RPC 扩展（media / ED2K / BitTorrent 增强、probe、resolveFilename、moveDownload 等）。 零依赖、无构建，直接用浏览器打开即可。
